# Impresiones3D-back

Este proyecto es el backend de una plataforma de gestión para servicios de impresión 3D. Su objetivo principal es administrar pedidos, clientes, modelos, estados y usuarios relacionados con el proceso de impresión 3D, facilitando la organización y el control del flujo de trabajo.

## Características principales

- Gestión de usuarios y control de acceso.
- Administración de pedidos y seguimiento del estado de impresión.
- Catálogo de modelos y manejo de archivos relacionados con impresiones 3D.
- API para integración con interfaces web o móviles.

El sistema está diseñado para ser flexible, escalable y fácil de usar
