# Impresiones3D-back

Este repositorio contiene el código del backend para la plataforma de gestión de servicios de impresión 3D. El sistema está diseñado para administrar pedidos, clientes, modelos, estados de impresión y usuarios, facilitando la organización y el control integral del flujo de trabajo en talleres o empresas dedicadas a la impresión 3D.

## Propósito del Proyecto

El objetivo principal es proporcionar una solución robusta y escalable que permita gestionar de forma eficiente todas las operaciones relacionadas con la impresión 3D, desde la recepción de pedidos hasta la entrega final al cliente, incluyendo el manejo de catálogos y el control de acceso de usuarios.

---

## Características Principales

1. **Gestión de Usuarios y Control de Acceso**
   - Registro, autenticación y administración de diferentes tipos de usuarios.
   - Control de permisos y roles para operaciones seguras.

2. **Administración de Pedidos**
   - Creación y seguimiento de pedidos de impresión 3D.
   - Actualización de estados y notificaciones asociadas al avance de los pedidos.

3. **Catálogo de Modelos**
   - Almacenamiento y gestión de modelos 3D disponibles para impresión.
   - Manejo de archivos y metadatos asociados a cada modelo.

4. **API para Integración**
   - Endpoints RESTful que permiten la integración con interfaces web y móviles.
   - Documentación clara para facilitar el consumo de los servicios por parte del frontend u otros sistemas.

---

## Tecnología Utilizada

- **Lenguaje:** java
- **Framework:** React
- **Autenticación:** JWT
